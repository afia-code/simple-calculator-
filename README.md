# 🧮 C++ Calculator
Command-line calculator built in C++ featuring basic mathematical operations (addition, subtraction, multiplication, division) with user-friendly menu interface
## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Continuous calculation mode
- ❌ Error handling (division by zero)
